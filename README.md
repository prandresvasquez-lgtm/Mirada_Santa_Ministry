# Mirada Santa Ministry
Mini sitio web estático listo para GitHub Pages.

## Publicación
1. Crea un repositorio público en GitHub, por ejemplo `mirada-santa-ministry`.
2. Sube `index.html` y `logo.jpg` a la raíz del repositorio (no la carpeta que los contiene).
3. En **Settings → Pages**, selecciona **Deploy from a branch**, rama **main**, carpeta **/(root)** y guarda.
4. GitHub mostrará la URL pública cuando termine el despliegue.

Para actualizar enlaces, horarios o textos, edita `index.html`.
